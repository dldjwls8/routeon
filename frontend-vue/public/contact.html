문의

계정 접근, 기업 승인, 오더·배차 테스트, 기사 앱 연동 오류는 재현 정보와 함께 RouteOn 팀 담당자에게 전달해 주세요.

문의 대상

  • 관리자·기사·슈퍼관리자 계정 접근 문제
  • 기업 가입 승인 또는 반려 관련 확인
  • 오더 접수, 배차 생성, 운행 상태 동기화 오류
  • 기사 앱 운행 목록, 위치 전송, 취소 요청 관련 문제

전달하면 좋은 정보

  • 사용한 계정 역할과 기업명
  • 문제가 발생한 화면 또는 API 경로
  • 오더 ID, Trip ID, 기사 ID 등 식별자
  • 발생 시각, 재현 순서, 앱 로그

처리 방식

팀 내부 담당자가 테스트 계정, 서버 로그, 앱 로그를 확인한 뒤 원인을 분류합니다. 코드 수정이 필요한 경우 변경 이력과 문서에 반영합니다.

바로가기

서비스 사용 중이라면 대시보드 또는 로그인 화면으로 돌아가 문제 화면을 다시 확인할 수 있습니다.
