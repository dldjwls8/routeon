저작권 안내

RouteOn 프로젝트의 화면, 코드, 문서, 로고, 발표 자료는 졸업작품 산출물입니다. 외부 자료는 각 제공처의 라이선스와 이용 조건을 따릅니다.

1. 프로젝트 산출물

RouteOn의 웹 화면, 기사 앱 연동 구조, API 설계, 문서, 로고 및 발표용 자료의 권리는 RouteOn Team에 있습니다.

2. 외부 라이브러리와 API

  • 지도, 주소 검색, 경로 계산, UI 라이브러리, 오픈소스 패키지는 각 제공처의 라이선스를 따릅니다.
  • 공공데이터 기반 휴게소·차고지·물류단지 자료는 해당 데이터 제공 기관의 이용 조건을 따릅니다.
  • 외부 API 응답과 지도 타일은 RouteOn Team의 소유물이 아닙니다.

3. 사용 제한

  • 팀 동의 없이 프로젝트 산출물을 상업적 목적으로 복제, 배포, 판매하지 않습니다.
  • 시연·평가·포트폴리오 목적의 인용은 출처를 표시하는 것을 원칙으로 합니다.
  • 실제 서비스 출시 또는 외부 배포 시 라이선스 검토를 별도로 진행해야 합니다.
