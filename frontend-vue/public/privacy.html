개인정보 처리방침

RouteOn은 졸업작품 시연 및 기능 검증에 필요한 범위에서만 개인정보와 운행 관련 데이터를 다룹니다. 실제 운영 전까지 테스트 데이터 사용을 원칙으로 합니다.

1. 처리하는 정보

  • 계정 정보: 로그인 ID, 이름, 이메일, 전화번호, 역할, 소속 기업
  • 기사 정보: 면허번호, 차량 연결 정보, 기사 상태, 위치 로그
  • 운영 정보: 오더 주소, 담당자 연락처, 화물 정보, 배차·운행 이력
  • 시스템 정보: 로그인 토큰, 채팅 메시지, 오류 재현에 필요한 요청 기록

2. 이용 목적

  • 계정 인증 및 권한 확인
  • 기업·기사 승인, 차량·오더 관리, 배차 생성
  • 기사 앱 운행 목록, 위치 표시, 취소 요청 처리
  • 오류 분석, 기능 개선, 발표 시연 준비

3. 보관 및 삭제

프로젝트 운영, 발표, 검증 기간 동안 데이터를 보관할 수 있습니다. 불필요하거나 잘못 입력된 테스트 데이터는 관리자 요청에 따라 삭제 또는 정리할 수 있습니다.

4. 위치 정보

기사 앱에서 전송되는 위치 정보는 운행 상태 확인, 차량 위치 표시, GPS 기반 완료 검증을 위해 사용됩니다. 시연 환경에서는 실제 운행자의 지속 위치 추적 용도로 사용하지 않습니다.

5. 제3자 제공

개인정보를 외부 상업 서비스에 판매하거나 제공하지 않습니다. 지도, 주소 검색, 경로 계산 등 외부 API 사용 시 해당 API 제공자의 정책이 함께 적용될 수 있습니다.

6. 문의

개인정보 정정·삭제 또는 계정 접근 문제는 문의 페이지를 통해 요청할 수 있습니다.
